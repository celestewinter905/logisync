# Mobile Docs

Documentation hub for `apps/mobile` (the LogiSync Expo app).

## Quick start

```bash
pnpm --filter @logisync/mobile dev
```

If the starter scaffold needs to be reset:

```bash
pnpm --filter @logisync/mobile reset-project
```
